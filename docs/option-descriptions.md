# 投票短名称与详细说明

候选项保留已有 name 字段（现在用于简短名称），新增可选 description（默认空字符串，最多512字符）。vote.opened.options、vote.snapshot.options、vote.closed.final_options 以及 game.sync 内的对应对象使用相同约定。event_id、event_key、choice 与投票结算规则不变。

游戏端负责生成说明，并使用该轮实际执行命令的参数；后端校验、转发并保存到重连快照。Bot 在开票公告及恢复中的开票公告展示“短名称＋换行说明”，票况与结果仍保持简洁。旧客户端缺少 description 时维持只显示名称的行为。

例如名称“蓄力爆发”，说明“普通弹冻结5秒，再以150%速度运动2秒，不含激光。”

## 更新顺序

1. 更新并重启投票后端，加入可选字段支持。
2. 更新 AstrBot 插件目录中的 logic.py（或更新整个插件），在面板重载插件。
3. 换用本次编译的 x64 thchaos.exe，保留同目录 freetype.dll，重新启动游戏并注入。

旧后端采用严格字段校验，会拒绝新游戏端的 description；因此不能先只更新游戏端。新后端支持旧游戏端。旧 Bot 忽略额外字段，只显示短名称；更新 Bot 后才有详细说明。

本轮仅更新本地源码与构建，不自动部署远程后端，不发送群消息。
